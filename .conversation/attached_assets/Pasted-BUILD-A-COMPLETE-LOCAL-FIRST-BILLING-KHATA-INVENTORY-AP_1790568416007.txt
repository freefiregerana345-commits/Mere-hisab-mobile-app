BUILD A COMPLETE LOCAL-FIRST BILLING + KHATA + INVENTORY APP

Build a complete, production-ready Android-first business management application inspired by the useful functionality of popular Indian billing and khata applications such as MyBillBook and Khatabook.

IMPORTANT:
Do NOT copy their source code, logos, copyrighted assets, exact UI, or proprietary designs.

Create an ORIGINAL application with its own branding, UI, components, layouts and code.

The application should combine:

- Billing
- Khata / Ledger
- Customer management
- Supplier management
- Inventory
- Sales
- Purchases
- Expenses
- Payment tracking
- Reports
- Invoice customization
- UPI payment information
- WhatsApp Business sharing/redirect
- A4 printing
- Mini thermal printer printing
- PDF generation
- Local backup/restore
- Multiple local users
- Unlimited records
- Offline-first operation

The application should be completely free to use.

---

1. MOST IMPORTANT REQUIREMENT — LOCAL STORAGE ONLY

THIS IS A LOCAL-FIRST APPLICATION.

Do NOT use:

- Firebase
- Supabase
- MongoDB Atlas
- PostgreSQL cloud
- MySQL cloud
- Any paid database
- Any cloud database
- Any mandatory online server
- Any paid API
- Any subscription
- Any usage limit
- Any per-invoice charge
- Any per-customer charge
- Any per-bill charge

All business data must be stored locally on the user's device.

The application should use an appropriate local database such as:

- IndexedDB
- SQLite
- OPFS
- or another reliable local storage/database solution.

Choose the best option for a React/TypeScript PWA running on Android.

The application must continue working without internet.

Internet should only be needed for optional external actions such as opening WhatsApp Business.
